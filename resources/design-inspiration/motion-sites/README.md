---

## 🌐 What is MotionSites?

MotionSites is a curated gallery of high-concept web designs combining **cinematic video loops, 3D elements, typography layering, and interactive micro-animations**. 

When building landing pages with AI coding assistants (Claude Code, Cursor, Antigravity), standard prompts often result in flat, boring cards. MotionSites provides the exact **prompts, layout blueprints, and hosted media** needed to create immersive websites that look like they were built by a luxury design agency.

## 🚀 How to Use for Web Projects

1. **Browse for Inspiration:** Open [https://motionsites.ai](https://motionsites.ai/) or browse `examples/INDEX.md` to find an aesthetic you like.
2. **Pick Media:** Copy a hosted video URL from `media/MEDIA.md` for your hero background.
3. **Feed to Your Agent:** Paste the corresponding prompt from `examples/` into your coding agent along with the Framer Motion rules from `skills/design/framer-motion/AGENTS.md`.
