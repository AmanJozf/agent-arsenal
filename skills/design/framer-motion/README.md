# 💫 Framer Motion: Production React Animation Engine

> Based on the modern standard for web animation by [Motion.dev](https://motion.dev/) & [Framer Motion](https://github.com/motiondivision/motion).

Equips AI coding agents with production spring physics, shared layout transitions (`layoutId`), scroll-linked triggers (`useScroll`), and exit animations (`AnimatePresence`) for React and Next.js.

## 💡 What This Does

* **Organic Spring Physics:** Replaces stiff linear animations with calibrated spring presets (`snappy`, `smooth`, `gentle`) that feel tactile and responsive.
* **Shared Layout Morphing (`layoutId`):** Automatically animates geometry changes between components—like sliding pill indicators across tabs or expanding cards into full-screen dialogs.
* **GPU-Composited:** Enforces hardware-accelerated animations (`transform`, `opacity`) to maintain a steady 60fps and eliminate layout shifts.
* **Pre-Built Patterns:** Ready-to-copy code in `patterns/`:
  - `patterns/floating-tabs.tsx`: Smooth animated pill indicator tab bar
  - `patterns/magnetic-card.tsx`: Interactive 3D tilt card responding to mouse movement
