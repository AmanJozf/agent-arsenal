# Framer Motion Skill

Equips your AI coding agent with the motion design principles, spring physics formulas, and performance patterns of Framer Motion (Motion).

## Capabilities
- **Spring Physics Engine:** Pre-configured springs (snappy, smooth, gentle) for organic movement.
- **Shared Layout Transitions:** `layoutId` pill indicators, card expansions, and reordering lists.
- **Scroll Triggers:** `useScroll`, `useTransform`, and `useInView` for sticky reveals and parallax effects.
- **A11y Support:** Automatic reduced-motion fallbacks for accessible animation.

## Usage
Ask your agent to animate any UI element:
```text
/framer-motion Add smooth spring hover states and an expandable card layout using layoutId
```
