# 🖼️ Image-to-Code: Image-First Art Direction & Implementation

> Part of the [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) suite.

An image-first art direction and implementation skill for AI coding assistants. Focuses on turning visual mockups, hero sections, and landing page designs into clean, responsive frontend code without falling into typical AI layout mistakes.

---

## ⚡ How to Install on Any Machine (2-Line Guide)

```bash
# Copy the universal Image-to-Code rules into your project
curl -fsSL https://raw.githubusercontent.com/AmanJozf/agent-arsenal/main/skills/design/image-to-code-skill/AGENTS.md -o AGENTS.md
```

---

## 💡 What This Does

* **Spacious Hero Sections:** Ensures the top of the page remains readable and visible on small laptop displays without awkward crowding.
* **Anti-Nesting Engine:** Prevents the dreaded "cards-inside-cards-inside-cards" UI look that makes websites feel like generic prototypes.
* **Section-by-Section Precision:** Focuses on high fidelity per component rather than generating a half-baked skeleton.
