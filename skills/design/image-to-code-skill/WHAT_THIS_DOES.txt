WHAT THIS DOES:

REAL EXAMPLE:
You provide a mockup image of an editorial product page and say:
"Turn this design mockup into a live Next.js + Tailwind hero section."
The agent analyzes the typography scale, whitespace ratios, and visual balance to code an exact, un-bloated match.
