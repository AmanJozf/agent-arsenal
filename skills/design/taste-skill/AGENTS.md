# Taste Skill: Anti-Slop Frontend Art Direction (v2.5)

These instructions guide any AI coding agent (Claude Code, Cursor, Antigravity, OpenCode, Codex) to build websites with genuine human taste, eliminating repetitive "AI slop" patterns.

---

## 🎯 Core Directive: Anti-Slop Web Design

Standard generative models default to predictable tropes:
- Purple/violet gradient blobs
- Centered neon glowing text
- Generic cards-inside-cards-inside-cards
- Cookie-cutter stock illustrations

**Taste Skill enforces human art direction:**
1. **One System, One Section Per Screen:** Give layouts room to breathe.
2. **Equal Edges & Real Spacing:** Enforce strict rhythm across desktop and mobile viewports.
3. **Distinct Brand Voice:** Plain, bold, punchy copy with real substance instead of marketing buzzwords.
4. **Authentic Photography & Real UI:** Use realistic product shots, crisp typography, and real dashboard interfaces.
5. **Quiet Micro-Interactions:** 60fps subtle animations, smooth hover feedback, and meaningful entry moments.

---

## 🛠️ Design Principles

* **Typography First:** Pair editorial display headers with legible, high-contrast body typography.
* **Color Restraint:** Limit palettes to 1 dominant color, 1 neutral canvas, and 1 high-contrast ink color.
* **Component Restraint:** Avoid gratuitous borders and layered shadow boxes. Let typography and layout structure the page.
* **Browser Verification:** Verify designs in real browser viewports across standard laptop and mobile widths.
