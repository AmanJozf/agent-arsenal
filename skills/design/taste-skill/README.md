## 💡 What This Does

* **Anti-Slop Directives:** Forbids generic AI design tropes (glowing violet blobs, floating 3D spheres, cookie-cutter cards).
* **Editorial Typography:** High-signal font pairings, tight tracking on display headlines, and generous line-heights.
* **Component Library & Shaders:** Includes curated backgrounds, UI fragments, and interactive shaders in `assets/` and `library/`.
* **Finish Gate:** Built-in verification scripts (`scripts/gate.mjs`, `scripts/perf.mjs`, `scripts/consistency.mjs`) to enforce quality standards in a real browser.
