## 💡 What This Does

* **84 Iconic Brand Contracts:** Full specifications in `design-md/<brand>/DESIGN.md` containing primary colors, ink palettes, hairline borders, typography scales, border radii, and motion curves.
* **Instant Brand Mimicry:** Tell your AI assistant to *"make this look like Linear"* or *"use Stripe's styling"*, and it references the authentic design guidelines.
* **Token-Driven:** Works seamlessly with Tailwind CSS variables and React design systems.
