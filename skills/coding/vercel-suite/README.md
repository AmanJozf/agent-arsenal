## 💡 What This Does

* **`react-best-practices`:** 45 battle-tested rules for React Server Components (RSC), `<Suspense>` streaming, bundle splitting, and memory leak prevention.
* **`react-view-transitions`:** Native CSS View Transitions integration for Next.js to give multi-page apps app-like navigation smoothness.
* **`composition-patterns`:** Clean architectural patterns for building flexible, slot-based UI components without prop explosion.
* **`deploy-to-vercel`:** Automates project linking, environment variable setup, and preview deployments directly from the agent.
* **`vercel-optimize`:** Automated Core Web Vitals (LCP, FID, CLS) audit and remediation runbooks.
