# 🪨 Caveman: Terse Mode & Token-Saving Engineering Suite

> Based on the viral token-optimization project by [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman).

Strips conversational filler, narrative preambles, and polite padding from AI coding assistants. Forces terse, high-signal responses, concise Conventional Commits, and compressed memory files while preserving 100% code accuracy.

---

## ⚡ How to Install on Any Machine (2-Line Guide)

```bash
# Add universal Caveman terse instructions into your project
curl -fsSL https://raw.githubusercontent.com/AmanJozf/agent-arsenal/main/skills/coding/caveman/AGENTS.md -o AGENTS.md
```

---

## 💡 What This Does

* **Terse Caveman Voice:** Eliminates up to 70% of unnecessary conversational output tokens (*"Certainly! I'd be happy to explain..."* → *"Port in use. Kill PID."*).
* **`caveman-commit`:** Generates minimal, single-line Conventional Commit messages capped at 50–72 characters without conversational bloat.
* **`caveman-compress`:** Optimizes project memory files (`CLAUDE.md`, `AGENTS.md`) into high-density tokens to preserve context windows.
* **`surgical-patch` & `verify-and-stop`:** Makes isolated, minimal diffs and halts without unprompted lectures.
